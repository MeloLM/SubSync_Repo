# Istruzioni di progetto — SubSync

**Leggi `AI_law_subsync.md` nella root, per intero, prima di eseguire qualsiasi
modifica al codice.**

Quel file è l'unico documento normativo del progetto: contiene le regole
architetturali vincolanti, la gestione del diario di bordo, le regole della
documentazione a macro-aree per Obsidian, le direttive operative, le convenzioni di
nomenclatura e i vincoli di ambiente e build.

Questo file non contiene regole proprie: esiste solo perché Claude Code lo carica
automaticamente all'avvio della sessione, e serve a puntare al documento normativo.
Se una regola sembra vivere qui, è un residuo da spostare in `AI_law_subsync.md`.
